# ClothManager
### Система учета, подбора и продажи товаров одежды

![Delphi](https://img.shields.io/badge/Delphi-12_Athens-E62429?style=for-the-badge&logo=delphi&logoColor=white)
![Language](https://img.shields.io/badge/Language-Object_Pascal-B31942?style=for-the-badge)
![Platform](https://img.shields.io/badge/Platform-Windows_10/11-0078D6?style=for-the-badge)

**ClothManager** — это консольное приложение на языке Object Pascal, разработанное для автоматизации учета товарных остатков и подбора одежды на складе. Программа позволяет вести два связанных справочника (типы одежды и конкретные товары), осуществлять полный цикл CRUD-операций, подбирать товары по заданным критериям и оформлять покупки с генерацией кассовых чеков.

---

## Основные возможности

-  **Два связанных справочника:** Управление типами одежды (с привязкой к сезону) и конкретными товарами.
-  **Полный CRUD:** Добавление, удаление, редактирование и поиск записей с проверкой целостности данных.
-  **Гибкий поиск и сортировка:** Поиск по множеству параметров (код, бренд, размер, пол, сезон) и сортировка списков.
-  **Умный подбор:** Фильтрация товаров по сезону, полу и размеру с автоматической сортировкой по возрастанию цены.
-  **Оформление покупок:** Автоматическое списание товара со склада и генерация кассового чека в текстовый файл.
-  **Надежное хранение:** Данные сохраняются в типизированных бинарных файлах и загружаются в оперативную память через односвязные динамические списки.
-  **Защита от ошибок:** Консольный интерфейс с валидацией ввода (защита от нечисловых значений, пустых строк и выхода за пределы диапазонов).

---

## Архитектура и структура модулей

Проект имеет модульную архитектуру с четким разделением ответственности (Business Logic отделена от UI и Storage):

| Модуль | Назначение |
| :--- | :--- |
| `ClothManager.dpr` | Точка входа, инициализация списков и главного цикла программы. |
| `ClothTypeRepo.pas` | CRUD-операции для справочника типов одежды. |
| `ClothRepo.pas` | CRUD-операции для справочника товаров. |
| `Utils.pas` | Утилитарный модуль: безопасный ввод данных и валидация. |
| `FileStorage.pas` | Загрузка данных из бинарных файлов в списки и сохранение обратно. |
| `UIManager.pas` | Отрисовка консольного интерфейса, меню и таблиц. |

- **ОС:** Windows 10 / 11
- **ОЗУ:** не менее 32 МБ
- **Свободное место на диске:** от 5 МБ
- **Дополнительное ПО:** Не требуется (поставляется в виде готового `.exe`)
